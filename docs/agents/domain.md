# Domain documentation

StopLore uses a single context: root `GLOSSARY.md` and `docs/adr/`.

Before exploring domain code:

1. Read the root glossary.
2. Read ADRs relevant to the work.

Use glossary terms in specifications, explanations, code, and test names.
Surface conflicts with an ADR explicitly before proposing a different decision.
Distinguish accepted target designs from behavior verified in the implementation.

If domain documents are missing, proceed silently. Domain modeling creates them
when terminology or decisions are resolved.
